# nitinol-eventsource

CQRS + Event Sourcing integration layer for the `nitinol` framework. Provides
the core abstractions (`Aggregate`, `Decider`, `Receive`, `Projector`,
`Snapshotable`, `Effect`) on top of the `nitinol-runtime` actor model.

See [docs.rs](https://docs.rs/nitinol-eventsource) for API documentation.
