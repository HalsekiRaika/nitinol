## Report Phaseとの境界

- Workflow ContextのReport DirectoryはPhase 1では読み取り専用です。
- `docs-review.md`を直接変更しないでください。
- 修正結果はPhase 1の最終回答として返してください。レポート保存はTAKTのReport Phaseが担当します。

## Docs Review
{report:docs-review.md}

## docs-only 修正手順

1. `docs-review.md`の各findingを、修正前に現在のファイル・diff・正本で再検証してください。
2. 各findingの観点IDを確認してください。
   - D1: チェックリスト記載漏れ
   - D2: 正本との矛盾
   - D3: doc build / link / quality gate等の機械的問題
   - D4: docs-only範囲外の変更混入
3. D1〜D4に該当しない指摘は「対象外」と記録し、修正しないでください。
   文体・語調・一般的な構成改善・チェックリスト外提案を取り込まないでください。
4. 有効なfindingだけを最小範囲で修正してください。
5. **プロダクションコードの挙動を変更しないでください。**
   docs-only範囲で修正不能なら、コード変更で回避せずplanへ差し戻してください。
6. D2は必ず正本を再確認してから文書を修正してください。
7. D3は該当する機械的検証を再実行してください。
8. D4では、今回のdocs-only作業が追加した範囲外変更だけを除去してください。
   タスク開始前から存在する無関係な差分を勝手に変更しないでください。
9. 修正後に全findingを再照合し、残存するD1〜D4 findingがなければ「修正完了」と判定してください。
